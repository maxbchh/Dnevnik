# Журнал ДЖД

Стартовый проект электронного дневника для учебной группы проводников. Интерфейс на русском, адаптивный для телефона и компьютера.

## Возможности первой версии
- регистрация по email и паролю с отображаемым именем;
- роли: начальник поезда (`owner`), учитель (`teacher`), проводник (`conductor`);
- оценки 1–10 и отдельная отметка `Н`;
- посещаемость: был / Н / опоздал;
- график созвонов и занятий с темой и домашним заданием;
- примечания преподавателей;
- общая база Supabase, Row Level Security и обновления в реальном времени между устройствами.

## 1. Создать Supabase-проект
В Supabase открой SQL Editor, вставь целиком `supabase/schema.sql` и выполни.

## 2. Назначить себя начальником поезда
Сначала зарегистрируй свой аккаунт через сайт. Затем в SQL Editor выполни запрос, заменив email на свой:
```sql
update public.profiles p
set role = 'owner'
from auth.users u
where u.id = p.id and u.email = 'твой-email@example.com';
```
Второго ЛНП зарегистрируй обычным аккаунтом. В кабинете открой «Проводники» и нажми «Назначить учителем» напротив его имени.

## 3. Подключить сайт
Скопируй `.env.example` в `.env` и вставь из Supabase Project URL и Publishable/anon key в `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Не используй `service_role` или secret key в браузере.

## 4. Запуск
Требуется Node.js LTS:
```powershell
npm install
npm run dev
```
Для production-сборки: `npm run build`.

## Публикация на GitHub Pages
В настройках Pages выбери GitHub Actions и добавь workflow для Vite с переменными окружения Supabase. Одного выбора Pages недостаточно: сначала нужно загрузить все исходники и настроить секреты/variables.

## Важно
Это стартовая версия, не проверенная на production. Перед реальным использованием протестируй роли и RLS на тестовых аккаунтах. Не публикуй персональные данные участников без согласия.
