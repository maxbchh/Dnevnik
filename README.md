# Журнал ДЖД

Учебный электронный журнал проводников детской железной дороги.

Исходная версия проекта находится в архиве `railway-journal-starter.zip`. Для публикации приложения загрузите содержимое архива в корень репозитория, затем настройте Supabase по инструкции в `README.md` из архива.

Дизайн: Liquid Glass, адаптивный интерфейс. Разделы: главная, проводники, оценки, посещаемость, график занятий и примечания.
